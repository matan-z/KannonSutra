# 開発ログ — 観音経 暗記道場

Claude Code（Claude）とのやりとりの記録。音声生成は Codex が別に担当しており、その作業内容はこのログには含まれていない（Claude が確認した範囲だけを書く）。

---

## 2026-10-17

### 1. 構成の検討と初版の作成
**依頼**: 観音経を楽しく暗記して、ひとりで読経できるようになる HTML ゲームを作りたい。まずは GUI だけにし、音声（別の AI で生成）と 3D（Blender と Codex で作る）は後から入れる。

**決めたこと**
| 項目 | 決定 |
|---|---|
| 範囲 | 世尊偈（104句・5字1句） |
| 読み | 一般的な呉音読み（データ側で差し替えられるようにする） |
| 技術 | Vanilla HTML/CSS/JS（ES Modules）、ビルド不要、外部ライブラリなし |
| 方針 | データ・ゲームの仕組み・描画・音声を分けておき、音声と 3D を後から差し込める作りにする |

**作ったもの**
- 経文データ（[sekai-ge.js](../js/data/sekai-ge.js)）: 104句を、漢字・1字ずつの読み・句番号・段（13段×8句）で持つ
- 修行モード5つ: 経本・穴埋め・次の句は？・並べ替え・ひとり読経
- 記憶度: 句ごとに0〜5で記録し、3以上を「覚えた」とする。段の全句が3以上で「成就」し、次の段が開く
- 演出: 正解で花びら、連続正解の表示、ホームの108玉の数珠と開いていく蓮、成就したときの満開の蓮
- 設定: ルビ、縦書き／横書き、文字サイズ、全段解放、記録リセット
- 音声と描画を差し替えるための入口: [audioService.js](../js/audio/audioService.js)、[visual/index.js](../js/visual/index.js)

**確認**: ヘッドレス Chrome で全モードを自動で通しプレイし、エラーなし。
- 縦書きの経本で、1列に句が詰まりすぎる問題があった。1行（縦書きでは1列）2句の経本の体裁に直した
- 並べ替えで、スマホでは札が画面外に押し出されていた。札を小さくして直した

### 2. ひとり読経の答えにルビを表示
**依頼**: ひとり読経で答えを見たときにルビを付けてほしい。
**原因**: 経本モードの「ルビ」ボタンでルビをオフにすると、それがひとり読経にも効いていた。
**対応**: 答えを見た句だけは、ルビ設定がオフでも読みを表示するようにした。伏せている句には読みを出さない。

### 3. 現代語訳を覚えられるようにする
**依頼**: 現代語訳も覚えられるようにしたい。
**対応**
- 104句すべてに、句ごとの現代語訳（意訳）を付けた。偈の4句を続けて読むと一文になる
- 新モード「⑤ 意味あわせ」を追加: 句から訳、訳から句を交互に4択で答える。ひとり読経は⑥に繰り下げ
- 訳の表示: 経本では読んでいる偈の訳、ひとり読経では答えを見たときの訳、段の画面では一覧に訳を出す
- 意味の記憶度は、読みとは別に記録する（キーは `m1`, `m2`…）。段の成就は読みだけで判定する
- 設定に「現代語訳を表示」を追加

**メモ**: 作業中に、Codex が経本モード（learn.js）と音声まわりを音声対応に書き換えていたことに気付いた。その版を残したまま訳の表示を組み込んだ。

### 4. Codex の音声生成の確認（レビュー）
**依頼**: Codex で音声を生成して組み込んだので確認してほしい。

**問題なかった点**: ゆっくり版と通し読み版の2種類が104句そろっており、区間の重なりや欠けはない。経文を書き換えると、ずれた範囲の音声は自動で使えなくなる。生成スクリプトのテストは5件とも成功。ブラウザでも再生でき、文字の強調も音声に合わせて進んだ。

**指摘した点**
1. 誤読が3句あった（起動中の VOICEVOX で全句の発音を確認した）
   - 9「弘誓深如海」・13「我為汝略説」: 「にょ」が「ニ・ヨ」に分かれて読まれる
   - 82「慧日破諸闇」: 「は」が助詞の「ワ」として読まれる
   - カタカナで渡すと上の3句は直るが、今度は1・20・38・73・84 で「ミョウ→ミヨウ」などの別の誤読が出る
2. 通し読み版で、文字の強調が一部飛ぶ（第一段の40字中4字）。再生位置の通知が約0.25秒おきで粗いため
3. どこからも使われていない重複ファイルなど、約49MB の不要分がある

**結果**: Codex が参考の読経音声をもとに音程の不自然さを直している最中のため、**音声まわりの修正は保留**となった。

### 5. 結び（長行）の追加
**依頼**: 「是故応頂礼」のあとの部分がないので追加してほしい。
**対応**
- 「爾時持地菩薩 … 阿耨多羅三藐三菩提心」の15句を、第十四段「結び（持地菩薩）」（105〜119句）として追加した。読みと現代語訳も付けた。全体は119句、14段になった
- 音声生成スクリプトが読む `ROWS`（偈104句）とは分けて、`PROSE_ROWS` に置いた。Codex の作業に影響しないようにするため
- 経本の訳表示は「結び（1）〜（3）」の文ごとにした。縦書きパネルは縦にもスクロールできるようにした

**影響**: 結びの音声がないため、ホームの「通しで読む」（全119句）では音声が選べなくなった。

**照合が必要な読み**: 105句目の「爾時（にじ）」、117句目の「衆中（しゅちゅう／しゅうちゅう）」。

### 6. 経題の追加
**依頼**: 第一段の前に「妙法蓮華経観世音菩薩普門品第二十五偈」を加えてほしい。
**対応**
- 経題（読みは「みょうほうれんげきょう かんぜおんぼさつ ふもんぼん だいにじゅうごげ」）を、番号のない見出しとして追加した（データでは `SUTRA_TITLE`）
- 表示する場所: 第一段と通し読経の経本・ひとり読経の先頭（朱色・ルビ付き）、第一段の画面、ホームの小見出し

**判断**: 句として足すと句番号が1つずつずれ、保存済みの記憶度や音声との対応が崩れる。そのため、経本での強調・ゲーム・記憶度の対象外にした。対象にする場合は、音声作業が終わってから行う。

### 7. 未解放の段を鍵マークに
**依頼**: 「未解放」の文字を鍵マークにしてほしい。
**対応**: ホームの段一覧を鍵のアイコンにした（画面読み上げでは「未解放」と読まれる）。
